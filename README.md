# QCyber AI - LLM Red Teaming & CTF Challenge 🛡️

**QCyber AI** هي منصة تفاعلية متطورة ومحاكاة احترافية لتحديات التقاط العلامة (CTF) واختبار اختراق نماذج الذكاء الاصطناعي (LLM Red Teaming). تم تصميم المنصة وفقاً لأحدث معايير الأمان العالمية وتصنيفات **OWASP LLM Top 10**.

## 🎯 مميزات المنصة (Features)

* **21 مستوى تصاعدي:** تغطي ثغرات حرجة مثل (Direct Prompt Injection, Jailbreaking, Indirect Injection, SSRF, XSS via LLM Output, Chain-of-Thought Hijacking).
* **مؤشر خطورة تفاعلي (WAF Risk Calculator):** محاكاة حقيقية لتقييم مدى شبهة وخطورة التوجيه المدخل لحظياً.
* **نظام شهادات إتمام ديناميكي:** القدرة على توليد وتحميل شهادة احترافية عند إنهاء جميع المستويات بنجاح.
* **تصميم عصري (Dark Mode UI):** واجهة مستخدم مخصصة لمهندسي الأمن السيبراني والباحثين بتجربة تفاعلية سلسة.
* **شرح ثغرات مدمج:** لكل مستوى تفاصيل واضحة حول الآلية الأمنية وكيفية الترقيع (Remediation).


تنبيه أخلاقي: تم إنشاء هذه المنصة حصرياً لأغراض التعليم والتدريب على أمان الذكاء الاصطناعي واختبار الاختراق الأخلاقي
